接口与口径

  • 官方 API 可稳定覆盖 Spot、Margin、USD-M Futures、COIN-M Futures；本看板已合并这些口径。
  • Alpha 活动页的“资产/积分”统计属于网页/App 登录态内部口径，目前没有公开 API-key 接口。
  • Earn、Funding、Launchpool、Alpha 私有活动口径如果也要纳入，需要额外确认对应接口或抓包验证。
